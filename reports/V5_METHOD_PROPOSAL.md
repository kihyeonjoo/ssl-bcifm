# V5 방법 제안서: 자극 시점 정렬 캘리브레이션 (SLA)

작성 2026-10-04 03:00.  **평가용 제안서다 — 방법 실험은 하지 않았고, 성립성 진단(gate 0)만 했다.**

## 한 줄 요약

새 사용자가 캘리브레이션 때 보는 영상은 학습 피험자들도 본 **같은 영상**이다.  지금은 그
영상에서 평균(중심화)과 감정 라벨(L3)만 쓴다.  **같은 영상·같은 시점에서 학습 피험자들이
보인 평균 응답**을 대응점으로 쓰면, 같은 시청 시간에 감정 라벨 없이 세션별 회전을 정할
제약이 감정 수(3·5개)에서 창 수(수백 개)로 늘어난다.  fMRI 의 response hyperalignment 를
EEG 파운데이션 모델의 배포 시점 캘리브레이션으로 옮긴 것이다.

## 1. 출발점 — 우리 데이터가 말하는 남은 문제

| 단계 | 결과 | 근거 |
|---|---|---|
| 오프셋 (1차 모멘트) | 라벨 없이 잡힌다 — 중심화 SEED +0.07~+0.10, SEED-V +0.066~+0.079 (13~16/16) | S13, V1 |
| 분산 (2차) | 기여 없음 — stratified norm Holm 0/16 | V2 |
| 남은 오차 | 사용자·세션마다 다른 **클래스 방향 회전**, 감정 정보와 얽힘 → 라벨 없는 적응은 중심화가 천장 | V3, S10 |
| 감정 라벨로 회전을 잡으면 | 클립 전체에서만 SEED-V +0.03~+0.04, SEED +0.01~+0.015.  짧은 예산은 0 또는 음수 | V4, V4 부록 A |
| **라벨 방법 셋이 같은 곳에 닿는다** | L2 회전·L3 혼합·L4 head 의 클립 전체 정확도 차이 ≤ 0.01 | V4 부록 A |

마지막 줄이 출발점이다.  **방법이 아니라 제약의 양이 병목**으로 보인다 (가설).  감정당
1클립이면 세션당 대응점이 감정 수(SEED 3, SEED-V 5)뿐이고, 200차원 특징의 회전을 그것으로
정할 수 없어 모든 방법이 강한 수축(선택된 β·λ 대부분 0.25~0.5)에 기댄다.

## 2. 방법이 만족해야 할 조건

1. **시청 시간을 늘리지 않는다** — 예산은 시청 시간이다 (S8, S9).
2. **세션마다 추정한다** — 회전이 사용자·세션마다 제각각이라 전역 보정은 해로웠다 (V3 2b, −0.025).
3. **평가 데이터의 pseudo-label 에 기대지 않는다** — M2·T3A·adaBN·LA 모두 0 (S10).
4. **평가 데이터의 성질을 쓰지 않는다** — 클래스 균형, 평가 클립의 자극 정체성.  벤치마크 설계를
   이용하는 것이고 배포에서는 성립하지 않는다 (Veilleux et al. 2021 의 비판과 같은 이유).

## 4. 추천: SLA (Stimulus-Locked Alignment)

### 4.1 아이디어

fMRI 에서는 새 피험자에게 **표준 영화를 보여 주고, 시점별 응답을 집단 평균 응답에 직교 변환으로
맞춰** 집단 모델을 옮겨 쓴다 (response hyperalignment — Haxby et al. 2011, 2020; 새 피험자
적용 예 Jiahui et al. 2020).  같은 자극을 본 시점 대응이 피험자 사이 좌표계를 맞추는 공짜
감독 신호다.

우리 데이터가 정확히 이 구조다 (2026-10-04 캐시에서 확인):
- **SEED**: 15명이 세 세션 모두 **같은 15개 영상을 같은 순서로** 봤다 (클립 길이·라벨 전원 동일).
- **SEED-V**: 세션마다 영상 세트는 다르지만 **같은 세션 안에서는 16명 모두 같은 영상**이다.
- 캘리브레이션 클립은 실험자가 고르므로 정체성과 시점을 안다.  클립 안 창 번호 = 영상 시점이다
  (`_slice_trial` 이 처음부터 4초씩 자르고 캐시는 섞지 않았다).

지금의 CR/L3 는 캘리브레이션 클립에서 **감정당 평균 1개**만 쓴다.  SLA 는 같은 클립의 **창마다**
대응점을 만든다.

### 4.2 알고리즘

**학습 시 (한 번)** — 세션 a, 클립 k, 시점 t 의 집단 템플릿:

    T[a,k,t] = mean_{s ∈ 학습 피험자} ( z[s,a,k,t] − μ[s,a] )

**배포 시** — 새 사용자의 세션 d, 캘리브레이션 클립 집합 C (감정당 1개, 앞 T초 또는 전체):

1. μ_d = 캘리브레이션 창 평균 (지금의 중심화 그대로)
2. X = { z[d,k,t] − μ_d },  Y = { T[d,k,t] } − (Y 의 캘리브레이션 평균),   (k,t) ∈ C
3. U = [X; Y] 의 상위 k 주성분,  R = Procrustes(XU, YU),
   W = (1−β)·I + β·( I + U (R − I) Uᵀ )
4. (선택) 감정 라벨 항 — Procrustes 교차공분산에 γ·(감정 평균 M_c → 학습 prototype P_c) 를 더하거나,
   W 를 적용한 뒤 L3
5. 평가 창: ẑ = (z − μ_d) W → 학습 prototype 최근접 (조건4).  클립은 평균 특징으로.

초매개변수 (k, β, γ) 는 fold 마다 검증 피험자 2명으로 고른다 (V4 와 같은 절차).  계산은 200×200
SVD 하나다.

### 4.3 왜 병목을 겨냥하는가

| | CR / L3 (지금) | SLA |
|---|---|---|
| 세션당 대응점 | 감정 수 (SEED 3, SEED-V 5) | 캘리브레이션 창 수 (클립 전체 기준 SEED ≈ 170, SEED-V ≈ 210) |
| 필요한 정보 | 감정 라벨 | **자극 정체성과 시점만** (감정 라벨 불필요) |
| 짧은 예산 | 감정이 아직 특징에 안 실려 실패한다 (S11) | 감각 응답은 영상 시작부터 있다 → **짧은 예산에서도 대응점이 생긴다** (가설) |
| 대응 목표 | 감정 평균 → 감정 prototype (클립 고유 성분이 섞임) | 같은 클립 → **같은 클립의 템플릿** (자극 고유 성분까지 맞춤) |

### 4.4 성립성 진단 (gate 0) — 방법 평가가 아니다

no-EA 팔 특징, 진단 편의상 도메인 전체 중심화.  감정 라벨·정확도는 쓰지 않았다.
스크립트: [analyze_isc_feasibility.py](../analyze_isc_feasibility.py),
[analyze_isc_roles.py](../analyze_isc_roles.py), [analyze_isc_cv.py](../analyze_isc_cv.py).

| 질문 | SEED | SEED-V |
|---|---|---|
| 보지 못한 피험자도 같은 시점 신호를 공유하나 (동적 ISC vs 시점을 원형 이동한 귀무) | **+0.071** vs −0.001, **15/15** | **+0.074** vs −0.006, **16/16** |
| 감정을 넘는 자극 고유 신호가 있나 (클립 평균: 같은 클립 vs 같은 감정 다른 클립) | +0.017, 14/15 | +0.027, 14/16 |
| 학습 > 보지 못한 피험자인가 (동적 ISC 학습 / 검증 / 테스트) | 0.100 / 0.075 / 0.071 | 0.105 / 0.078 / 0.074 |
| **캘리브레이션 클립으로 맞춘 회전이 다른 클립의 공유 구조를 늘리나** (k=50, β=0.5, 감정당 1클립 전체) | 정적 0.588 → **0.631** (13/15), 동적 +0.009 (14/15) | 정적 0.241 → **0.309** (14/16), 동적 +0.009 (14/16) |
| 같은 것을 수축 없이 (β=1) | 동적 −0.004 (과적합) | 동적 −0.012 |

**읽는 법.**  공유 신호는 작지만 (코사인 0.07) 모든 피험자에 있고, 보지 못한 피험자에서 학습
피험자보다 약 30% 낮다 — V3 의 "학습 ≫ 검증 ≈ 테스트" 가 시점 신호에서도 반복된다.
**캘리브레이션 클립만으로 맞춘 회전이 다른 클립에서도 집단과의 일치를 높이므로, 어긋남은 클립이
아니라 세션 단위이고 감정 라벨 없이 일부 추정된다.**  수축은 필수다.
회전 설정은 네 가지(k 10·20·50, β 0.5·1.0)를 봤고 β=0.5 인 두 설정이 모두 개선했다 — 표의 값은
설정을 고른 진단값이지 방법의 추정치가 아니다.  gate 1 에서는 검증 피험자로 고른다.

**아직 모르는 것: 그 정렬이 감정 정확도를 올리는가.**  공유 구조의 상당 부분은 감정과 무관한
감각 응답일 수 있다.  이것이 gate 1 의 질문이다.  (±1창 지연 허용 결과는 셋 중 최댓값을 고르는
선택 편향이 섞여 있어 해석하지 않는다.)

### 4.5 선행연구 대비 위치

| 연구 | 하는 것 | SLA 와의 차이 |
|---|---|---|
| Hyperalignment (Haxby 2011, 2020), SRM (Chen 2015) | fMRI, 같은 영화의 시점 응답으로 피험자 정렬 | 모달리티·과제가 다르다 (EEG 파운데이션 특징, 감정 분류).  배포 시점 시청 예산으로 평가 |
| RSRM 의 EEG 적용 (2021) | 운동 상상 EEG 에 공유 응답 모델 | 학습 단계 차원 축소.  자연 자극 시점 대응이 아니다 |
| CLISA (Shen 2022), TA2CL (2026) | 같은 영상 구간을 양성 쌍으로 **학습 단계** 대조학습 | SLA 는 **배포 시점**, 재학습 없이, 새 사용자의 세션마다 |
| SCORE (2026) | EEG→이미지 검색에서 새 피험자 좌표를 직교 변환으로 복원, 라벨 없음 | 대응점이 EEG–이미지 랜드마크 (교차 모달).  SLA 는 같은 영상의 시점 대응 |
| RPA (Rodrigues 2019), CR/L2 (우리) | 라벨 붙은 클래스 평균으로 회전 | SLA 는 감정 라벨 없이, 대응점이 수십 배 |
| EA (He & Wu 2020), 중심화 | 1·2차 모멘트 정렬 | SLA 는 그 위의 회전 |

**2026-10-04 검색 기준으로, EEG 감정 인식에서 새 사용자의 캘리브레이션 영상 시점 응답으로 배포
시점 정렬을 한 연구는 찾지 못했다.**  다만 hyperalignment 자체는 잘 알려진 기법이다.  그래서
기여는 "기법의 발명" 이 아니라 **"진단이 필요하다고 보인 바로 그 성분(세션 회전)을, 이미 지불한
캘리브레이션 시간에서 감정 라벨 없이 추정하는 방법" 과 그 검증**으로 세워야 한다.  SCORE 의
관찰("피험자들은 개념 사이 관계는 공유하지만 다른 좌표 방향으로 표현한다")은 우리 V3 와 같은
결론이라 동기를 받쳐 준다.

### 4.6 현실성 조건 — 지켜야 할 것

- 자극 정체성은 **캘리브레이션 클립에만** 쓴다.  평가 클립의 정체성·순서는 쓰지 않는다 (배포에서
  사용자가 보는 것은 임의의 콘텐츠다).
- 학습 코호트가 **같은 캘리브레이션 영상을 봤어야 한다** — "표준 캘리브레이션 영상" 이라는 배포
  설계 가정으로 명시한다.  SEED, SEED-V, FACED 모두 이 조건을 만족한다.
- 중심화는 지금처럼 캘리브레이션 창에서만 한다.

## 6. 성공 시 논문 구조

가제: *Calibrate with a Movie: Stimulus-Locked Alignment for Cross-Subject EEG Emotion
Recognition with Foundation Models*

1. **진단** — 중심화 뒤 남은 오차는 세션별 회전이고, 라벨 없는 적응은 그 천장에 막힌다
   (V2·V3, 사전 등록, SEED-V 재현).
2. **방법** — 캘리브레이션 영상의 시점 대응으로 그 회전을 추정하는 SLA.  감정 라벨 0, 추가 시청 0.
3. **평가** — 시청 시간 예산, 사전 등록, 3 데이터셋 × 2 파운데이션 모델.

학회: AAAI / IJCAI / ACM MM (BK IF4, Regular).

## 7. 실패해도 남는 것 — 결과가 남은 회전의 정체를 가른다

| 결과 | 뜻 |
|---|---|
| SLA 가 된다 | 회전은 **세션 좌표계 전체의 성질**(전극 위치·접촉 등)이고 감각 응답으로도 잡힌다 |
| SLA 가 안 된다 | 회전은 **감정 응답에 고유한 개인차**이고 감정 라벨로만 잡힌다 → 분석 논문의 "라벨 없는 천장" 이 더 단단해진다 |

어느 쪽이든 논문의 한 절이 된다.

## 8. 결정해 주실 것

1. **gate 1 (CPU 반나절) 을 진행할지.**  진행하면 판정 기준을 먼저 고정하고 돌린다.
2. gate 1 이 통과하면 gate 2 (FACED·CBraMod, GPU 수일) 를 할지 — 그때 다시 묻는다.
