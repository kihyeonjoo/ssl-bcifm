# 다음에 할 일

> ## ⚠ LaBraM 사전학습이 SEED 를 포함한다 — 논문에 명시할 것 (2026-09-30)
>
> LaBraM 논문 부록의 사전학습 데이터 목록에 **SEED, SEED-IV, SEED-GER, SEED-FRA**
> 와 PhysioNet MI 가 들어 있다.  따라서 우리 SEED LOSO 의 **테스트 피험자 EEG 가
> 사전학습(라벨 없음)에 이미 쓰였다.**
>
> 라벨은 안 봤으므로 라벨 누출은 아니지만, **"처음 보는 피험자" 라는 전제가 표현
> 학습 단계에서는 성립하지 않는다.**  중심화가 그렇게 잘 듣는 이유 중 일부가 이것일
> 가능성을 배제할 수 없다.  논문에 명시하고, 핵심 결과는 **사전학습에 없던
> 데이터셋에서 재현**해야 한다.
>
> **SEED-V 는 LaBraM 사전학습에 포함되지 않았다** — SEED 계열 중 유일한 외부 검증
> 대상이다.  준비 상태는 아래 "S16 준비" 절에 있다.

> ### α 는 0.2 그대로 쓴다 (2026-09-30 결정)
>
> `measure_ea_scale.py --dataset {seed,seedv}` 로 재고 판단했다.
>
> | | scale100 (EA 전) | **diag EA α=0.2 적용 후** |
> |---|---|---|
> | SEED | 0.1278 | **0.118 ~ 0.158** |
> | SEED-V | 0.0829 | **0.155 ~ 0.191** |
>
> **비교해야 하는 것은 EA 후 값끼리다.**  diag EA 는 채널 공분산으로 진폭을 다시
> 정하므로 백본이 실제로 받는 크기는 원본 스케일이 아니라 **α 가 정한다.**  두
> 데이터셋의 EA 후 값이 같은 범위(0.12~0.19)에 있으므로 α=0.2 를 그대로 쓴다.
>
> (처음에 "SEED-V 기준값이 SEED 의 63% 이므로 α=0.2 면 입력이 2.3배 커진다" 고
> 적었는데, SEED-V 의 **EA 후** 값을 SEED 의 **EA 전** 값과 비교한 잘못된 대조였다.)
>
> **한 fold 로 α 를 비교하지 않는다.**  fold 하나의 차이는 시드 간 실행 잡음
> (SEED 기준 window sd 0.0284) 보다 작아 아무것도 가를 수 없다.
>
> **SEED-V 에서 재현이 실패하면 그때 α 민감도를 별도로 잰다** — 16 fold × 3 seed 를
> α 두 값으로 돌리는 것이 유일하게 판정 가능한 설계이고, 재현이 성공하면 그 비용을
> 쓸 이유가 없다.

## 0-X. 확정: 평가는 항상 `center_fresh_eval: true` (2026-09-25)

**앞으로 학습 중 중심화를 쓰는 모든 실행에서 val/test 도메인 평균을 평가 직전에 계산한다.**

원래 코드는 에폭 시작에 계산했는데 평가는 에폭 끝에 한다. 비교 대상인 오프라인 조건2
(clip 0.7180)는 채점하는 바로 그 가중치로 평균을 냈으므로, 고치지 않으면 평가 쪽만
낡은 불공정한 비교가 된다.

비용 **2.5초/epoch** (val 5,052창 + test 2,526창). 공정 비교의 전제이므로 선택 사항이
아니다.

> 이 결정으로 **평가 시점 낡음은 해결됐다.** 남은 것은 학습 시점 낡음뿐이고, 그것은
> 같은 체크포인트를 두 방식으로 채점해서는 알 수 없다 — 백본 자체가 다르게 학습되기
> 때문이다. [S5_STALENESS.md](S5_STALENESS.md) §5 의 선택지 C 는 보류한다.

### S8 에서 확정된 것 (2026-09-27, 학습 없음)

**EA 의 기전**: 후보 두 개가 기각되고 하나가 지지됐다.

EA 는 도메인 **사이**의 관계를 고치는 조작이 아니라 각 도메인 **안**의 신호를 좋게

정렬 기법이라면 도메인 간 분산이나 전이 격차가 줄어야 하는데 둘 다 일어나지 않았다.
각 도메인 안에서 무엇이 개선되는지는 **미측정**이다.

EA 는 교차 전이(+0.041)와 자기 도메인 상한(+0.032)을 **같은 양만큼 함께** 올리므로,
도메인 사이의 관계를 개선하는 게 아니라 각 도메인 안의 신호 품질을 개선한다.

**현실적 캘리브레이션 프로토콜** (평가 클립을 평균 계산에서 배제):

- **단일 감정 클립 캘리브레이션은 15/15 실패** (측정) — prototype 에서는 중심화를 안

  **휴식 상태는 SEED 에 휴식 구간이 없어 미측정** — 같은 이유로 실패할 가능성이 높다는
  것은 추정이다.
- 단일 상태밖에 없으면 prototype 대신 **head 경로**(조건2)를 쓸 것.

**따라서 기존 조건4 clip 0.7590 은 transductive 값이다.**

### S9 에서 확정된 것 (2026-09-27, 백본 학습 없음)

**중심화와 EA 를 모두 캘리브레이션 창에서만 계산한 최종 수치** — 이것이 보고할 값이다:

| 캘리브레이션 | clip | window |
|---|---|---|
| 3클립 (~11분) | **0.7262** | 0.6231 |
| 총 120초 | 0.6951 | 0.6143 |
| 총 60초 | 0.6785 | 0.6012 |

정직도 사다리 (조건4 clip): 전부 transductive 0.7590 → 중심화만 현실적 0.7301 →
**둘 다 현실적 0.7262** → 총 120초 0.6951 → 총 60초 0.6785 → 중심화 없음 0.6376 →
EA 도 없음 0.5964.

**EA 이득은 현실적 프로토콜에서 줄어든다.** 팔 전체 clip +0.0499 → 3클립 +0.0302
(p=0.048) → 총 120초 +0.0179 (p=0.21) → 총 60초 **+0.0111 (CI 0 포함)**.

교차 확인: **EA + 감정별 40초(0.6951) ≈ EA 없음 + 3클립 전체(0.6960).** 짧은
캘리브레이션에서는 EA 를 넣는 대신 중심화 데이터를 늘리는 쪽이 낫다.

**캘리브레이션 영상 다양성은 무관하다.** 고정 예산에서 감정당 클립 수 k=1~4 의 차이가
≤0.004 (p ≥ 0.35). 필요한 것은 세 감정 전부와 총량이지 영상 수가 아니다.

### S10 에서 확정된 것 (2026-09-28, 백본 학습 없음)

### S11 에서 확정된 것 (2026-09-28, 백본 학습 없음)

**감정 신호는 영상 시작 후 시간이 지나야 올라온다.** 클립 구간별 window 정확도

분류기 문제가 아니라 **특징에 감정 신호가 덜 실려 있는 것**이다.

**그러나 앞부분을 버리면 안 된다.** 시청 시간을 고정하고 앞 10·20초를 버리면 전부
0 이거나 약간 나쁘다 (시청 40초 clip −0.0064, p=0.025). 창이 줄어 생기는 손실이
품질 향상을 상쇄한다. 캘리브레이션 영상 설계의 답은 **"길게 보여줄 것"** 이다.

**자극 라벨(실험자가 아는 영상의 감정)은 짧은 시청에서 해롭다.** 시청 20~40초에서

피험자가 나빠진다. 원인은 **라벨은 맞는데 특징이 아직 그 감정을 담고 있지 않다는
것** — 캘리브레이션 감정별 평균의 정답 prototype 코사인이 시청 20초 **0.48**,
40초 0.56, 클립 전체 0.73 이다. 분석 C 와 같은 곡선이다.

클립 전체(~11분)에서만 이득이 있고, 최대는 **L4(head 마지막 층 적응) head_clip
+0.0284** (p=0.004, 12/15) → 0.7373.

> **2026-09-28 정정.** 그 +0.0284 의 비교 상대는 같은 경로의 조건2 다.
> 실제 최선인 **조건4 와 짝지어 재면 clip 에서 유의하지 않다**
> (+0.0073, CI [−0.0075, +0.0220], p=0.39, 10/15). window 에서만 유의하다
> (+0.0121, p=0.010, 11/15).

어느 쪽이든 S2 라벨 상한(0.8464, 44클립 라벨)의 **5% 미만**이다.

짧아도 좋으니 여러 감정을 포함한 캘리브레이션이 선행돼야 한다.

테스트 세션의 **라벨 없는** 특징 평균을 빼는 것이 전부다. EA 와 같은 transductive 가정이다.

### 이득의 출처가 갈렸다

| 조건 | clip | Δ vs 조건1 | 판정 |
|---|---|---|---|
| 1 head, 중심화 없음 (= A팔) | 0.6336 | 기준 | |
| 2 head, **중심화** | 0.7180 | +0.0844 | 유의 |
| 3 prototype, 중심화 없음 | 0.6385 | +0.0049 | **CI 가 0 포함 — 효과 없음** |
| 4 prototype, 중심화 | 0.7590 | **+0.1254** | 유의, 15/15 |

**최근접 분류라는 결정 규칙 자체는 아무 일도 하지 않는다.** 이득은 중심화에서 온다.

### 조건과 한계

| | |
|---|---|
| 클래스 불균형 | **강건** (5클립->2클립, 최악 −0.016) |
| 캘리브레이션 | ~~여러 클립에 걸친 30초면 충분~~ — **transductive 값이었다.** 현실적으로는 총 24초가 31.6%, 120초가 57.0%, 3클립 전체가 75.1% ([S8](S8_TRANSFER_AND_CALIB.md)) |

### 판정 기준 — 두 종류를 구분한다

| 종류 | 기준 |
|---|---|
| **결정 규칙만 바꿈** (재학습 없음) | 그 비교의 CI / Wilcoxon / 이긴 수 |
| **재학습 필요** (다른 학습 실행끼리) | 최소 감지 효과 **+0.0386** |

+0.0386 은 시드 잡음을 포함한 값이라, 같은 체크포인트에서 결정 규칙만 바꾼 비교에
적용하면 효과를 과소평가한다. 중심화는 전자에 속한다.

**질문**: 테스트 피험자의 EA 변환을 세션 전체가 아니라 앞부분 N초로만 만들면 성능이 얼마나 남는가.

**가설**: 대각 EA는 추정할 값이 62개(채널 분산)라, 1,953개(62×62 공분산)를 추정하는
원래 EA보다 짧은 캘리브레이션에서 훨씬 잘 버틴다.

**설계**
- 학습 피험자는 기존대로 세션 전체로 정렬
- **테스트 피험자의 변환만** 각 세션 앞부분 N초로 추정
- N = 10초, 30초, 60초, 300초, 전체
- 원래 EA와 대각 EA 둘 다
- 모델은 fold당 한 번 학습, 평가만 N을 바꿔 반복
- 평가 대상은 캘리브레이션 구간 이후 구간만 (앞부분을 평가에 섞으면 유리해짐)

**산출물**: 캘리브레이션 길이 대 정확도 곡선, 원래 EA와 대각 EA 두 줄.

## B-2. 필요한 캘리브레이션 길이를 라벨 없이 예측하기 (B와 함께)

**목표**: 테스트 피험자의 라벨 없는 데이터만 보고 "몇 초면 충분한가"를 미리 정하는 규칙.

**카오스 이론은 쓰지 않는다.** 캘리브레이션 길이는 "공분산 추정이 언제 안정되는가"라는
통계 추정 문제이고, 리아푸노프 지수는 궤적의 예측 가능성을 재는 다른 질문이다.
시간 척도도 1초 미만 대 수십 초~수 분으로 맞지 않고, EEG의 저차원 카오스 가정은
대리 데이터 검정 이후 약해진 전제다.

**방법** (학습 불필요, CPU 몇 분, 스레드 제한 필수)
1. **수렴 곡선**: 세션 앞부분 N초로 구한 공분산과 세션 전체 공분산 사이의 거리를
   N을 늘리며 잰다. 원래 EA는 전체 공분산의 리만 거리, 대각 EA는 채널 분산의 로그 비율.
2. **유효 샘플 수**: 채널별 자기상관 시간으로 초당 실제 독립 샘플 수를 추정하고,
   추정할 값의 개수(대각 62, 원래 1,953)로 이론적 수렴 속도를 계산한다.
3. **비정상성**: 세션 안에서 공분산이 시간에 따라 흘러가는 정도. 앞부분만으로는
   아무리 길어도 메울 수 없는 몫이 있는지 본다.

**검증**: 수렴 곡선의 꺾이는 지점이 실험 B의 정확도가 평평해지는 지점과 일치하는가.
일치하면 "라벨 없이 이만큼만 녹화하면 된다"는 규칙이 선다. 이 비교가 B-2의 핵심이다.

## C. LaBraM 구조의 문제 (2026-09-23 정리, 근거 강도 순)

1. **입력 진폭 정규화가 없다** — 근거 강함.
   전역 상수 `/100`뿐이고 TemporalConv가 원시 진폭을 그대로 토큰화한다.
   SEED 피험자 간 진폭 차 20배. 피험자별 채널 표준화(대각 EA)만으로 +6%p.
   → 후속: 모델 안에 **스스로 진폭을 맞추는 정규화 층**을 넣어 calibration 없이 같은 효과가 나는지.
2. **사전학습이 피험자 정체성을 학습한다** — 근거 강함.
   프로브 피험자 식별 0.79(동결) → 0.89(파인튜닝). Identity Trap(arXiv:2606.06647)도 같은 방향.
   within에선 LaBraM이 EEGNet을 크게 이기고(70.9 vs 52.7) cross에선 비슷(55.8 vs 52.3)
   → 사전학습 이득이 "같은 사람 알아보기"에서 나옴. 고치려면 재사전학습 필요, 우리 규모론 어려움.
3. **시간 맥락이 짧다** — 추론, 미측정.
   패치 1초·시간 임베딩 최대 16개 → 구조적으로 16초 이상 못 봄. 우리는 4초 창.
   → 확인됨(A-2): 클립 단위로 모으면 +0.076. 긴 맥락이 실제로 부족했다.
4. **채널 구성에 묶여 있다** — 근거 중간, 엇갈림.
   62→35채널 두 번 통과에서 손해, 한 번 통과로 회복. 그러나 미러링 위치 ID는 무영향(p=0.72).
- 아님: **파라미터 과다로 인한 과적합.** 학습 정확도 0.99로 과적합은 있으나, 학습 파라미터 3%인 LoRA가 성능을 못 바꿈.

## 꼭 읽을 논문

- **The Identity Trap in EEG Foundation Models** (Lin, Wu, Jung, arXiv:2606.06647) — 초록만 봄.
  파운데이션 모델 표현의 피험자 분산이 무작위의 13~89배, 파인튜닝 시 증가, "선형으로 제거 가능한 축".
  우리 GRL은 CLS에서 0.86→0.78밖에 못 내림 → 이들의 선형 제거 방식이 후속 실험 후보. 인용·차별화 필수.

for s in range(1, 16):
    print(f" {s:3d} |" + " ".join(f"{d[s][0]:8.4f}" if s in d else "       ·"
                                  for d in (E0, C0, E4, NM)))
for nm, d in (("E0", E0), ("C0", C0), ("E4-full", E4), ("E4-nomirror", NM)):
    v = [d[s][0] for s in sorted(d)]
    if v:
        print(f"{nm:14s} n={len(v):2d}  {np.mean(v):.4f} ± {np.std(v, ddof=1):.4f}")
for nm, a, b in (("nomirror vs E4-full", NM, E4), ("nomirror vs E0", NM, E0)):
    k = sorted(set(a) & set(b))
    if len(k) > 2:
        dd = [a[s][0] - b[s][0] for s in k]
        p = stats.ttest_rel([a[s][0] for s in k], [b[s][0] for s in k])[1]
        print(f"{nm:22s} n={len(k)}  Δ{np.mean(dd):+.4f}  개선 {sum(x>0 for x in dd)}/{len(dd)}  p={p:.4f}")
EOF

## 3. 해법 1 구현 — 단일 통과 토큰 분할 (구현 1시간 + 학습 5시간)

지금 구조의 문제는 **비대칭을 얻으려고 채널 분리라는 값을 치른 것**이다.
LaBraM을 35채널씩 두 번 돌리면 좌우를 잇는 attention이 사라지고,
62채널 전제로 사전학습된 모델에 낯선 입력이 들어간다.

해법은 한 번만 통과시키고 토큰에서 가르는 것이다. 코드로 이미 가능함을 확인했다.
`forward_features(..., return_patch_tokens=True)`가 `(B, 62*4, 200)`을 돌려주고,
LaBraM의 `TemporalConv`가 `B N A T -> B (N A) T`로 flatten하므로 채널 우선 순서다.

```python
tok = labram.forward_features(eeg, input_chans=all62,
                              return_patch_tokens=True)   # (B, C*P, D)
tok = tok.view(B, 62, P, D).mean(2)                       # (B, 62, D)
z_L = tok[:, LEFT_IDX].mean(1)
z_R = tok[:, RIGHT_IDX].mean(1)
# 이후 fusion은 기존과 동일
```

이득: 전체 attention 유지, 계산량 절반, **미러링 문제가 통째로 사라짐**.
`probe_subject_invariance.py`의 `extract()`에 이 방식이 이미 구현돼 있으니
거기서 가져오면 된다.

구현 위치는 `finetune_hemi_labram.py`의 `_encode_hemisphere` / `forward`.
새 config는 `seed_hemi_single.yaml`로 만들 것.

   나뉘고, 부족한 감정이 세션마다 바뀐다
2. 세션을 합치지 않음 → 문헌은 SEED-V 에서 3세션을 합쳐 학습한다

고친 결과: SEED 는 세션별 9/6 (`sd_pool_sessions: false`), SEED-V 는 클립 그룹
3폴드 + 세션 합침 (`sd_n_folds: 3`, `sd_pool_sessions: true`).  **비대칭은 문헌의
것이다.**  SEED-V SD 실행 수가 432 → **144** 로 줄었다.
