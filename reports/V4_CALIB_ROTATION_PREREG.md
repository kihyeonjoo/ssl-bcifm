# V4 사전 등록: 캘리브레이션 자극 라벨로 세션별 회전 (CR)

고정 시각: 2026-10-04 02:01 KST

## 동기 (V3 의 결론)

라벨 없는 적응은 중심화 근처가 천장이다.  남은 오차는 사용자·세션마다 다른 클래스 방향의
회전이고, 감정 정보와 얽혀 있어 전역적으로 지울 수 없다 (V3 2b).  세션마다 따로 추정해야
하는데 의사라벨로는 실패한다 (M2: clip 0).

그런데 중심화를 위해 이미 감정별로 한 편씩 보여주는 캘리브레이션 클립의 **자극 라벨**은
공짜다.  지금은 그것을 μ 계산에만 쓰고 라벨은 버린다.

## 방법 CR

테스트 세션 d 마다, 중심화와 **같은 캘리브레이션 창**에서:

1. μ_d = 캘리브레이션 창 평균 (기존 중심화와 동일)
2. 감정 c 의 캘리브레이션 창 평균 M_c (자극 라벨 사용, 중심화 후)
3. prototype 부분공간(+ 캘리브레이션 창의 PCA 축 k_extra 개) 안에서 M 을 학습 prototype P 에
   맞추는 Procrustes 회전 R, 단위행렬 쪽으로 β 만큼 수축: W = (1−β)I + β·R
4. 평가 창: (z − μ_d) W

`adapt_methods.m2_rotation` 을 그대로 쓰고 **라벨만 바꾼다** — M2 는 평가 클립의 의사라벨,
CR 은 캘리브레이션 클립의 자극 라벨.  **추가 시청 시간 0.**

초매개변수 (k_extra ∈ {0,2,5}, β ∈ {0.25,0.5,1.0}) 는 fold 마다 **검증 피험자 2명**으로
고른다 (M2 와 같은 절차).  테스트 피험자는 선택에 쓰지 않는다.

## 비교와 입력

- **기준선**: 같은 캘리브레이션 창으로 중심화만 (W = I).  같은 난수·같은 클립.
- **oracle**: 평가 클립 전체의 **참 라벨**로 회전 (k_extra=5, β=1) — 회전의 상한
- **주 입력: no-EA 팔** (cache_ft_noea, cache_ft_seedv_noea) — 입력 정규화에 테스트 데이터가
  전혀 쓰이지 않는 **완전히 현실적인** 파이프라인.
- 부 입력: EA 팔 (세션 전체 EA 포함) — 기존 수치와의 연결용
- 예산: 감정별 20초 / 40초 / 클립 전체 (앞부분), 반복 10, 지표 clip (조건4 prototype)

## 판단 기준 (주 입력 = no-EA 팔, Holm 족 = 2 데이터셋 × 3 예산 = 6 검정)

| 판정 | 조건 |
|---|---|
| **성공** | 두 데이터셋 모두 클립 전체 예산에서 Δ(CR − 중심화) ≥ **+0.015** 이고 Holm p < 0.05, 그리고 20초·40초에서 Δ ≥ 0 |
| **부분** | 한 데이터셋 이상에서 클립 전체 Δ ≥ +0.015, Holm p < 0.05, 그리고 유의하게 음수인 예산 없음 |
| **실패** | 그 외 |

함께 보고: oracle 헤드룸 중 회수한 비율 (CR − 중심화) / (oracle − 중심화).

## 예측 (적어 둔다)

S11 에서 짧은 예산의 라벨은 해로웠다 — 영상 앞 20~40초에는 감정이 특징에 아직 실리지 않는다.
그래서 **클립 전체에서만 효과가 나고 20초에서는 0 이거나 음수**일 것으로 예측한다.

## 해석

1. **이미 지불한 캘리브레이션의 자극 라벨은 세션별 회전을 일부 잡는다 — 단 SEED-V 에서만.**
   추가 시청 시간 0 으로 SEED-V 클립 전체 +0.032 (15/16), 창 +0.018 (15/16).
2. **두 데이터셋이 갈리는 이유로 보이는 것**: 테스트 세션의 중심화된 클래스 prototype 과 학습
   prototype 의 코사인이 SEED 0.754, SEED-V **0.322** 다 (no-EA 팔, 탐색 계산).  SEED 는 이미
   거의 맞아 있어 회전할 것이 적고, 감정당 한 클립으로 추정한 회전의 잡음이 그 작은 여지를
   상쇄한다.  검증 피험자가 고른 β 는 대부분 0.25~0.5 (단위행렬 쪽으로 강한 수축) 였다.
   **데이터셋 2개로 세운 설명이라 가설이다.**
3. **탐색 (사전 등록 밖)**: 피험자별 CR 이득은 oracle 헤드룸과 양의 상관 (클립 전체 SEED
   ρ=+0.53, p=0.043; SEED-V ρ=+0.39, p=0.13) 이지만, 두 양이 같은 center 를 빼므로 center 의
   잡음이 상관을 부풀린다.  학습 prototype 과의 어긋남과는 약하다 (ρ −0.17 ~ −0.48, 모두
   p > 0.05).  **"어긋남이 큰 피험자일수록 더 돕는다" 는 피험자 단위로는 확인되지 않았다.**

## 논문에 대한 함의

- V3 의 결론("라벨 없는 적응은 중심화 근처가 천장")에 **"라벨이 있으면 일부 넘는다"** 가
  붙는다 — 그것도 새 라벨이 아니라 중심화를 위해 이미 보여 준 클립의 자극 라벨로.
  분석 → 필요한 최소 보정 구조의 **혼합 논문**에서 한 절이 될 수 있다.
- **방법 논문의 주 기여로 세우기에는 약하다.**  (a) 효과가 데이터셋 하나에서만 난다.
  (b) 방법 자체는 RPA (Rodrigues 2019) 의 라벨 회전을 특징 공간으로 옮긴 것이다.
  (c) 크기가 oracle 헤드룸의 9% 다.

# 부록 A — 같은 라벨로 다른 방법 (no-EA 팔)

**고정 시각: 2026-10-04 02:24 KST — 아래 규칙은 no-EA 팔 결과를 보기 전에 적는다.**

## 놓쳤던 연결

**CR 은 S11 분석 D 의 L2 와 같은 방법이다** (`m2_rotation` + 캘리브레이션 자극 라벨).  S11 은
SEED·SEED-V 의 **EA 팔**에서 L2 (회전), L3 (prototype 혼합), L4 (head 마지막 층 적응) 를 이미
쟀다.  CR 을 제안할 때 이 연결을 적지 않았다.  **V4 가 새로 더한 것은 (1) no-EA 팔 (완전히
현실적) 에서 (2) 사전 등록·Holm 보정으로 확인했다는 것**이다.

S11 의 EA 팔 결과 (클립 전체, proto_clip, 기준선 = 단순 평균 중심화):

| | L2 회전 | L3 prototype 혼합 |
|---|---|---|
| SEED | +0.0044 (p=0.48, 7/15) | +0.0057 (p=0.19, 10/15) |
| SEED-V | +0.0262 (p=0.012, 12/16) | **+0.0332** (p=0.002, 14/16) |

**같은 라벨로 더 단순한 L3 가 L2 보다 컸다.**  그러면 V4 해석의 "회전을 잡는다" 는 아직 서지
않는다 — 이득이 회전 때문인지, prototype 을 그 세션의 캘리브레이션 감정 평균 쪽으로 옮긴 덕인지
가를 수 없다.

## 질문과 실행

no-EA 팔에서도 L3 ≥ L2 인가?  [analyze_labelcalib.py](../analyze_labelcalib.py) 를 **그대로**
no-EA 캐시·no-EA head 체크포인트로 돌린다 (초매개변수 선택은 S11 과 같이 검증 피험자 2명,
선택 지표 proto_win).  출력은 `results/{,seedv_}labelcalib_noea.npz` (EA 팔 파일을 덮지 않는다).

## 결정 규칙 (고정)

1. 비교는 같은 실행 안의 **L3 − L2**, 클립 전체 예산, proto_clip, 짝지은 Wilcoxon.
2. **어느 데이터셋에서든 L2 가 L3 보다 유의하게 크면 (p < 0.05)** → 논문의 '최소 보정' 은
   L2/CR 로 쓴다.
3. **그 외에는** 더 단순한 **L3 를 주 방법**으로 쓰고, L2/CR 은 기전 해석(회전)으로만 둔다.
4. L3 에도 V4 와 같은 판정 기준 (성공/부분/실패, Holm 족 = 2 데이터셋 × 3 예산, 기준선 대비)
   을 적용해 함께 보고한다.
5. L4 (head 적응) 는 경로가 달라 (조건2 head) 이 결정에 넣지 않고 함께 보고만 한다.

**SEED 에서 회전의 효과는 0 근처에서 구현 세부에 따라 부호가 바뀐다** — 효과가 작다는 뜻이고,
SEED-V (+0.032 / +0.032) 는 두 구현이 일치한다.

아니라 캘리브레이션 라벨의 양(감정당 1클립)으로 보인다 (가설).
