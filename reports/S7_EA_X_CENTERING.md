# S7: 입력 EA × 특징 중심화 2×2

> ⚠ **이 보고서의 transductive 수치는 참고용이며 논문 수치가 아니다.**
> 평가 데이터를 미리 본 값이 섞여 있다. 인용할 최종 값은
> [S13_FINAL_LADDER.md](S13_FINAL_LADDER.md) 와 `results/final_tables.csv` 다.

2026-09-27. EA 없음 팔 설정 [configs/s5_noea.yaml](../configs/s5_noea.yaml),
로그 `noea_arm.log`, 결과 `results/noea.csv` (45행).
특징 캐시 `cache_ft_noea/` (45개, 2.6 GB), 분석

결과 `results/ea_x_centering.npz`.

## 왜 했나

두 가지가 미결이었다.

1. **EA 이득이 실재하나.** 기존 +0.0357 은 1회 실행 대 1회 실행이었고 실행 잡음
   0.0284 를 넘지 못했다. 시드 3개 대 시드 3개로 다시 재야 했다.
2. **중심화가 EA 를 대체하나.** 둘 다 도메인 차이를 없애려는 조작이다. 중심화가
   EA 가 하는 일을 이미 다 하고 있다면 입력 EA 를 버릴 수 있다.

EA 없음 팔은 15 fold × 3 seed, 27시간 53분, 45/45 정상 종료. 설정 차이는
`ea: true→false` 와 출력 경로뿐이다. EA 키들은 남아 있으나 `SEEDRawDataset.__init__`
이 `ea` 가 True 일 때만 `_fit_alignment` 를 부르므로 무효이고, 대신
`norm: scale100` (`eeg / 100.0`) 이 적용된다.

## 결과 1 — EA 이득은 실재한다

15명, 시드 3개 평균끼리 대응비교.

| | EA 없음 | A팔 (diag EA α=0.2) | 효과 | 95% CI | 이긴 수 | 대응 t | Wilcoxon |
|---|---|---|---|---|---|---|---|
| window | 0.5451 | 0.5858 | **+0.0407** | [+0.016, +0.067] | 10/15 | 0.0097 | 0.0215 |
| clip | 0.5837 | 0.6336 | **+0.0499** | [+0.015, +0.084] | 13/15 | 0.0139 | 0.0115 |

**기존 기록 "EA 이득 +0.0357, 감지 한계 미달" 은 정정된다.** 공정 비교에서 이득은
오히려 커지고 두 지표 · 두 검정 모두 p<0.05 다.

**효과는 유의하고, 크기의 정밀도는 낮다.** CI 가 clip 에서 [+0.015, +0.084] 로
넓으니 "이득이 있다"는 확정이고 "이득이 +0.05 다"는 아니다. 최소 감지 효과 +0.0386 은
n=15 설계가 무엇을 잡을 수 있는지 미리 정하는 값이므로, 검정이 끝난 뒤 다시 관문으로
걸지 않는다. clip(+0.0499, 13/15)이 window 보다 이긴 수가 많다.

### 이득은 고르지 않다

| 피험자 | clip EA 효과 |
|---|---|
| 7 | **+0.178** |
| 9 | +0.141 |
| 13 | +0.104 |
| 14 | +0.089 |
| 10 | +0.082 |
| 8 | +0.067 |
| 나머지 8명 | −0.030 ~ +0.052 (시드 잡음 폭) |
| **6** | **−0.104** (확실한 손해) |

상위 6명이 전체 이득의 대부분을 만든다. "EA 는 평균적으로 도움이 되지만 모두에게
그렇지 않다" 가 정확한 서술이다.

### 시드 잡음은 EA 가 더 크다

| | window sd (평균/최대) | clip sd (평균/최대) |
|---|---|---|
| EA 없음 | 0.0257 / 0.0658 | 0.0450 / 0.0780 |
| A팔 | 0.0288 / 0.1093 | 0.0634 / 0.1992 |

EA 의 transductive 공분산 추정이 시드 간 변동을 키우는 쪽이다. clip 최대값이
0.078 → 0.199 로 벌어지는 게 두드러진다. 앞으로 A팔 기준 잡음을 쓸 때
**clip 0.0634** 를 쓰고, EA 없음 설정에서는 더 작은 값을 쓸 수 있다.

## 결과 2 — 중심화와 EA 는 가법적이다

조건1 = head / 중심화 없음, 조건4 = prototype / 중심화. clip 단위.

| | 조건1 | 조건4 | 중심화 효과 |
|---|---|---|---|
| EA 없음 | 0.5852 ± 0.1163 | 0.7111 ± 0.0951 | **+0.1259** (15/15) |
| A팔 | 0.6336 ± 0.1117 | **0.7590 ± 0.0699** | **+0.1254** (15/15) |
| EA 효과 | +0.0484 | +0.0479 | |

window 단위는 EA 없음 0.5467→0.5985 (+0.0518), A팔 0.5883→0.6317 (+0.0434).

**상호작용은 0 과 구별되지 않는다.** 피험자별 차이의 차이로 검정:

| 단위 | 상호작용 Δ | 95% CI | p |
|---|---|---|---|
| clip | +0.0005 | [−0.0311, +0.0341] | 0.755 |
| window | +0.0084 | [−0.0051, +0.0262] | 0.330 |

즉 **중심화는 EA 를 대체하지 않고, EA 도 중심화를 대체하지 않는다.** 둘을 같이
쓰는 게 맞고, 최선은 여전히 조건4 + EA = **clip 0.7590** 이다.

중심화는 두 팔 모두 **15명 전원** 에게 이득이다 (최소 EA 없음 +0.0148,
A팔 +0.0296 — 둘 다 피험자 15). EA 와 달리 예외가 없다.

### 피험자 6 — EA 의 손해는 1차 모멘트였다

| | 조건1 | 조건4 |
|---|---|---|
| EA 없음 | 0.5481 | 0.6963 |
| A팔 | **0.4444** | 0.7037 |

중심화 없이는 EA 가 이 피험자를 0.5481 → 0.4444 로 망가뜨리는데, 중심화하면
0.6963 vs 0.7037 로 차이가 사라진다. EA 가 이 피험자에게 입힌 손해는 **중심화가
제거하는 종류(도메인 평균 이동)** 였다. EA 의 유일한 확실한 실패 사례가 중심화와
함께 쓰면 사라진다는 뜻이고, 둘을 같이 쓰는 근거를 하나 더 준다.

### 불량 전극 가설도 기각 (공정 비교로 재계산)

"EA 의 큰 이득은 망가진 전극을 보정해서 생긴다"는 추측을 공정 비교로 다시 쟀다.
불량 세션(한 채널이 세션 파워의 50% 이상)을 하나라도 가진 피험자는 7명
(1, 2, 3, 5, 6, 7, 10), 나머지 8명.

| | clip EA 이득 | window EA 이득 |
|---|---|---|
| 불량 전극 7명 | +0.0296 | +0.0373 |
| 정상 8명 | **+0.0648** | +0.0454 |
| 차이 | −0.0352 (p=0.297) | −0.0081 (p=0.772) |

**방향이 반대다** — 불량 전극 피험자가 오히려 이득이 작다. 유의하지도 않다.
피험자 7 (F7 이 세 세션 모두 망가짐)이 최대 이득(+0.178)인 건 사실이지만, 같은 군의
피험자 6 이 최대 손해(−0.104)다. 이 군의 분산이 큰 것이고 체계적 경향은 없다.

## 결과 3 — EA 는 도메인 간 분산을 줄이지 않는다 (음성)

미세조정된 특징의 도메인 간 분산 비율 (S3 방식):

| | 분산 비율 | PCA 1축 | 90% 도달 |
|---|---|---|---|
| 사전학습 | 0.7969 | 0.646 | 4축 |
| EA 없음 | 0.1724 | 0.412 | 9축 |
| A팔 | 0.1495 | 0.334 | 9축 |

**차이 −0.0229, CI[−0.065, +0.017], Wilcoxon p=0.52, 줄어든 피험자 8/15 —
유의하지 않다.** 분산 감소량과 EA 이득의 상관도 없다 (Spearman r=−0.357, p=0.191).

0.7969 → 0.15~0.17 의 큰 감소는 **미세조정이 만든 것이고 EA 의 기여는 측정되지
않는다.** EA 가 왜 돕는지는 "특징 공간의 도메인 간 분산을 줄여서"로 설명되지
않으며, 이 보고서는 대체 설명을 제시하지 못한다.

## 남는 것

- EA 이득 +0.05(clip)는 실재하나 **정밀도가 낮고 6명에 집중**되며 1명에게 해롭다.
- EA 와 중심화는 **평균적으로 독립적으로 더해진다** (상호작용 ≈ 0). 단 이는 15명 평균의
  성질이고, 피험자 6 에서는 **EA 의 손해가 중심화가 제거하는 종류**였다 — 개별
  피험자 수준에서는 겹치는 부분이 있다.
- EA 의 기전은 **미설명**. 도메인 간 분산 가설은 기각됐다.
- EA 는 **시드 잡음을 키운다** — 앞으로 비교를 설계할 때 A팔 clip sd 0.0634 를 쓸 것.

### 검정하지 않은 것

- α 를 0.2 이외로 바꿨을 때 이 결론이 유지되는지. `DO_NOT_RUN_s0_diag_a0131.yaml` 은
  아직 돌리지 않았다.
- full EA (diag 아님) 와의 비교. `DO_NOT_RUN_s0_B_tracenorm.yaml` 도 미실행.
- 피험자 6 의 손해가 왜 생기는지 (해당 도메인의 R̄ 추정을 직접 보지 않았다).
- EA 가 시드 잡음을 키우는 기전. 관측했을 뿐 원인은 보지 않았다.
