## 1. 파워 불일치의 정체

`segment_power(X) = tr(XXᵀ)/T` — [alignment.py:44-46](../data/alignment.py#L44-L46)

- 평균을 빼지 않는다 (분산이 아니라 2차 모멘트). 단 DC 기여는 0.1–25% 로 작아 주원인이 아니다.
- **채널에 대한 '합'** 이라 최악 채널 하나가 전체를 좌우할 수 있다. "채널 std 중앙값" 은 그 채널을 무시한다.

S1 세션1:

| 채널 | std (µV) | 세션 파워 점유 |
|---|---|---|
| **PO6** | **6186** | **99.3%** |
| P1 | 507 | |
| 중앙값 채널 | 12.8 | |

파워는 PO6² 에 끌려 3.96e7, std 중앙값은 12.8. **450 배 차이는 전적으로 이 한 채널 때문이다.**

### 한 채널이 세션 파워의 50% 이상을 차지하는 경우: **45 세션 중 11개**

```
(1,1)  PO6  6186  99.3%     (10,2)  P1  199  67.4%
(5,1)   P7   259  86.0%     ( 6,1)  P1  193  64.2%
(2,2)   F7   246  81.3%     ( 7,3)  F7  140  63.1%
(5,3)   F7   121  70.2%     ( 7,2)  F7  140  63.1%
(1,2)   P1   196  60.3%     ( 7,1)  F7  138  60.5%
```

**F7 이 반복된다** — 피험자 7 은 세 세션 모두, 피험자 2·5 도. 특정 전극의 체계적 문제.

**결론: 계산 방식(채널 합)과 데이터 품질(망가진 전극) 양쪽이 원인이다.**

## 6. 진폭 클리핑이 필요한가 — **지금은 아니다**

| | EA 후 최대 채널 std | 상위 1% |
|---|---|---|
| (i) 현재 | 2.54 (기준의 20배) | 0.417 (3.3배) |
| (iii) trace | 2.38 (19배) | 0.419 (3.3배) |

- **상위 1% 가 기준의 3.3 배에 그친다.** 99% 의 세그먼트는 사전학습 분포와 비슷한 범위.
- 20 배는 세션당 한두 개 세그먼트 이야기이며 전체의 0.034%.
- **diag EA 자체가 이미 망가진 전극을 길들이고 있다.** scale100 에서 PO6 는 61.9
  (기준의 480배) 로 들어가지만 diag EA 후에는 다른 채널과 같은 α 가 된다. 클리핑이
  하려던 일을 EA 가 상당 부분 수행한다.

**판단: 클리핑은 해결해야 할 문제가 입증된 상태가 아니다.** 별도 변인으로 시험할 가치는
있으나, 지금 도입할 근거는 없다.

## 이 설계가 감지할 수 있는 최소 효과

| | 값 |
|---|---|
| 짝지은 차이의 sd (diag−EA없음, A팔 확정) | 0.0496 |
| 실행 잡음 (50 epoch, A팔 확정) | **0.0284** (최대 0.1070) |
| clip 단위 실행 잡음 | **0.0634** (최대 0.1992) |
| **n=15, α=0.05, power=0.80 의 최소 감지 효과** | **+0.0386** |

> **2026-09-25 갱신.** 이 절은 원래 2 epoch 스모크의 잡음 추정(0.0218)으로 계산해
> +0.032 를 썼다. A팔 45회가 끝나 실측한 값은 **0.0284** 로 30% 크고, 한계는
> **+0.0386** 이다. **B팔 취소 판단은 더 강해졌다.**

참고: EA 없음 → diag EA 는 +0.064 로 감지 가능. diag vs full 은 +0.013 으로 **감지 불가**
(p=0.31, 6/15) — 지금까지 diag 를 선호한 근거는 평균이 아니라 안정성(full 은 2 fold 를
3pp 넘게 악화, diag 는 0) 쪽에만 남는다.

### 고른다면: **(iii) trace 정규화, α = 0.171**

| 근거 | |
|---|---|
| 극단값 처리 최선 | 최대/중앙 18.6 (현재 19.9), p99 3.28 |
| 보통 세그먼트 품질 개선 | 중앙값기반 0.181 (현재 0.235) |
| 평균기반은 현재와 동등 | 0.41 vs 0.40 |
| 순환 논리 없음 | (iv) 와 달리 지표가 독립적 |
| 임의 상수 없음 | trim 의 절단 비율 같은 자의적 선택이 없다 |

원리: 각 세그먼트의 공분산을 trace 로 나눠 **진폭과 무관하게 동등 기여**하게 하고,
스케일은 중앙값 trace 로 되돌린다. 극단값 하나가 변환을 정하는 경로가 구조적으로 막힌다.

(ii) trim=0.20 을 고르지 않은 이유: 중앙값기반은 최선이나 평균기반과 극단값 처리가
모두 나빠진다. 한쪽을 개선하며 다른 쪽을 악화시키는 거래다.

### 그러나 **지금 돌리는 것은 권하지 않는다**

위 표의 품질 차이(중앙값기반 0.235 → 0.181)가 정확도 **+0.0386 이상**으로 번역될
가능성은 낮다. 25–40 GPU 시간을 쓰고 "차이 없음" 으로 끝날 공산이 크다.

대안:

1. **A팔 결과를 먼저 본다.** 50 epoch 의 실제 잡음이 0.022 보다 작으면 감지 한계가
   내려가고, 그때 다시 판단한다.
2. **B팔을 더 큰 변인으로 바꾼다** — 예: full vs diag 를 시드 3개로 제대로 붙인다.
   미해결 질문이고, 안정성 차이는 평균이 아니라 최악 사례라 감지 가능성이 있다.
3. **α 만 0.2 → 0.177 로 고치고** 이후 실험의 기본값으로 삼는다. 거의 무료.
