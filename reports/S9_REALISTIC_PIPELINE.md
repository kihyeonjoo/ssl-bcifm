# 분석 A: 감정 다양성인가, 영상 다양성인가 → **영상 다양성은 무관하다**

## 설계

S8 과 역할을 뒤집는다. 각 테스트 세션에서 **평가용으로 감정별 1클립씩 3클립**을 떼고,
남은 **12클립(감정별 4클립)을 캘리브레이션 풀**로 쓴다. 총 예산 B 안에서 감정당 클립
수 k 를 바꾸되 **총량은 창 단위로 정확히 고정**한다 — k 가 커지면 클립당 시간이 줄어
총 시간은 같다. 차이는 오직 다양성이다.

> 클립당 시간을 `ceil(B/3k)` 로 올림하면 k 가 큰 쪽이 총 시간을 더 쓰게 되어 비교가
> 무너진다. 그래서 창 `round(B/4)` 개를 3k 클립에 **최대한 고르게 배분**했고,
> `round(B/4) < 3k` 인 조합(예산 24초의 k=3,4)은 아예 건너뜠다.

## 결과 (조건4 prototype, window — 주 지표)

중심화 없음 0.5921, 12클립 전체 0.6309.

| 예산 | k=1 | k=2 | k=3 | k=4 | k=1 대비 최대 차이 |
|---|---|---|---|---|---|
| 24초 | 0.6204 | 0.6195 | (불가) | (불가) | −0.0009 (p=0.85) |
| 60초 | 0.6258 | 0.6223 | 0.6215 | 0.6237 | −0.0044 (p=0.42) |
| 120초 | 0.6262 | 0.6281 | 0.6266 | 0.6257 | +0.0019 (p=0.52) |

**모든 예산에서 k 의 영향이 ≤0.004 이고 CI 가 0 을 포함한다** (p ≥ 0.35).
조건2 head 도 같다 (최대 +0.0039, p=0.064).

## 해석

**제약은 총량이지 영상 다양성이 아니다.** 고정된 예산을 3클립에 몰아도 12클립에 펼쳐도
차이가 없다.

S8 의 결론은 그대로 남는다 — **세 감정이 모두 들어가는 것은 필수**(단일 감정은 15/15
실패)이지만, 그 위에 **영상 수를 늘리는 것은 무의미하다.** 필요한 것은 "여러 영상"이
아니라 "세 감정"이다.

이 실험의 검정력은 낮다는 점을 적어 둔다. 평가 세트가 세션당 3클립(피험자당 9클립)
뿐이다. 12클립 전체는 예산 24초 k=2 보다 +0.0114 높지만(p=0.018), 60초·120초와는
구별되지 않는다(p=0.19, 0.49). **"60초를 넘으면 11분을 더 써도 같다"가 아니라
"여기서는 그 차이를 잡을 수 없다"가 맞다** — S8 의 clip 곡선은 계속 오르고 있었다.

# 분석 B: EA 까지 현실적 캘리브레이션으로

S8 분석 2 는 중심화만 현실적 제약에 넣고 **EA 는 세션 전체로 R̄ 를 추정한 채** 뒀다.
여기서는 테스트 피험자의 **diag EA R̄ 와 중심화 μ 를 같은 캘리브레이션 창에서만**
계산한다. EA 가 바뀌면 백본 입력이 바뀌므로 테스트 피험자의 창을 GPU 로 다시
통과시켰다 (학습 피험자 쪽은 EA 가 도메인별이라 영향이 없어 `cache_ft/` 재사용).

`data/seed_raw_dataset.py` 에 `refit_alignment_explicit()` 를 추가했다 — 기존
`refit_alignment_limited` 는 "앞 N초"와 "무작위 N초"만 알고, 클립 단위 프로토콜은
호출자가 고른 세그먼트를 직접 넘겨야 한다.

> **검증.** 첫 체크포인트에서 세션 전체 EA 로 다시 인코딩해 `cache_ft` 와
> 조건1~4 가 일치하는지 확인했다 (최대 차이 **0.00040**). 특징 원소의 중앙값 차이는
> 0 이고 소수의 큰 활성값만 bf16 커널 누산 차이로 최대 2.3 어긋난다 — 배치 구성이
> 다르면 생기는 정상적인 차이다.

## (1) 완전히 현실적인 성능

조건4 prototype, n=15, 시드 3개 × 반복 10.

| 캘리브레이션 | 총량 | clip | window |
|---|---|---|---|
| 감정별 20초 | 60초 | 0.6785 ± 0.0665 | 0.6012 ± 0.0573 |
| 감정별 40초 | 120초 | 0.6951 ± 0.0672 | 0.6143 ± 0.0621 |
| 3클립 전체 | ~670초 | **0.7262 ± 0.0665** | **0.6231 ± 0.0633** |

### 정직도 사다리 (조건4 clip)

| | | 직전 대비 |
|---|---|---|
| 1. 전부 transductive (45클립 중심화 + 세션전체 EA) | 0.7590 | — |
| 2. 중심화 현실적(3클립) + EA 세션전체 | 0.7301 | −0.0289 |
| 3. **둘 다 현실적 (3클립)** | **0.7262** | −0.0038 |
| 4. 둘 다 현실적 (총 120초) | 0.6951 | −0.0312 |
| 5. 둘 다 현실적 (총 60초) | 0.6785 | −0.0166 |
| 6. EA 세션전체, 중심화 없음 | 0.6376 | −0.0409 |
| 7. EA 없음, 중심화 없음 | 0.5964 | −0.0412 |

**보고해야 할 수치는 0.7590 이 아니라 0.7262 다** (11분 캘리브레이션) 또는
**0.6785** (60초). 0.7590 은 평가 데이터를 미리 본 값이다.

## (2) 같은 현실적 조건에서 EA 있음 vs 없음

**재학습 비교**다 (두 팔이 다른 학습 실행). 최소 감지 효과 +0.0386 을 병기하되,
이는 **n=15 설계의 검정력 기준이고 유의성의 관문이 아니다** — 아래 일부는 +0.0386
아래이면서도 유의하다.

| 캘리브레이션 | clip 효과 | p | window 효과 | p |
|---|---|---|---|---|
| S7 팔 전체 (양쪽 세션전체) | **+0.0499** | 0.012 | **+0.0407** | 0.022 |
| 둘 다 현실적, 3클립 전체 | +0.0302 | **0.048** | +0.0290 | **0.005** |
| 둘 다 현실적, 총 120초 | +0.0179 | 0.208 | +0.0232 | **0.008** |
| 둘 다 현실적, 총 60초 | +0.0111 | 0.280 | +0.0125 | 0.083 |

**EA 의 이득은 현실적 프로토콜에서 줄어들고, 캘리브레이션이 짧아질수록 더 줄어든다.**
팔 전체 +0.0499 → 3클립 +0.0302 → 60초 +0.0111. 총 60초에서는 두 지표 모두 CI 가
0 을 포함한다.

조건2 head 도 같은 방향이다 (clip: Tfull +0.0319 p=0.055, T40 +0.0217 p=0.23,
T20 +0.0022 p=0.80).

교차 확인할 만한 값 하나: **EA 를 감정별 40초로 쓴 것(0.6951)이 EA 를 아예 안 쓰고
3클립 전체로 중심화한 것(0.6960)과 같다.** 짧은 캘리브레이션에서는 EA 를 넣는 대신
중심화 데이터를 늘리는 쪽이 낫다.

## (3) EA 를 transductive → 현실적으로 바꿀 때 잃는 양

| 캘리브레이션 | proto clip | proto window | head clip | head window |
|---|---|---|---|---|
| 총 60초 | −0.0151 (p=0.012) | −0.0203 (p=0.0003) | −0.0273 (p=0.002) | −0.0218 (p=0.0002) |
| 총 120초 | −0.0129 (p=0.004) | −0.0094 (p=0.003) | −0.0145 (p=0.004) | −0.0101 (p=0.0009) |
| 3클립 전체 | −0.0038 (p=0.16, 0포함) | −0.0040 (p=0.010) | −0.0048 (p=0.038) | −0.0032 (p=0.022, 0포함) |

**R̄ 를 11분에서 추정하면 손실이 거의 없고(−0.004), 60초에서 추정하면 −0.015~−0.027
잃는다.** diag EA 는 채널 분산 62개만 추정하므로 데이터 요구량이 적다는 기존 서술과
맞는다 — 다만 "적다"가 "60초로 충분하다"는 아니다.

## 정리

| 질문 | 답 |
|---|---|
| 캘리브레이션에 영상 다양성이 필요한가 | **아니다.** 고정 예산에서 k=1~4 차이 ≤0.004 |
| 무엇이 필요한가 | **세 감정 전부** (단일 감정은 15/15 실패, S8) 와 **총량** |
| 완전히 현실적인 최선 | **clip 0.7262** (11분), **0.6785** (60초) |
| EA 는 현실적 조건에서도 남는가 | **3클립에서는 남는다** (+0.030, p≤0.05). **60초에서는 구별되지 않는다** |
| EA 를 현실화하는 비용 | 11분 −0.004, 60초 −0.015~−0.027 |

## 검정하지 않은 것

- **학습 피험자 쪽 EA 는 여전히 세션 전체다.** 실전에서는 학습 데이터를 전부 보유하므로
  이것은 현실적 가정이지만, "모든 EA 가 현실적" 인 설정은 아니다.
- α 를 0.2 이외로 두었을 때 현실적 EA 의 손실이 달라지는지.
- 캘리브레이션 창을 클립 앞부분이 아니라 클립 전체에서 고르게 뽑을 때 (S3 의 "무작위"에
  해당). 여기서는 항상 앞부분이다.
- 분석 A 의 낮은 검정력 때문에 "60초 이후 포화" 는 판정되지 않았다. S8 의 clip 곡선과
  합치면 오히려 **포화하지 않는다**는 쪽이다.
