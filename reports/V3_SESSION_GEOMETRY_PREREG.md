# V3 사전 등록: 세션 기하 진단 — 결과를 보기 전에 고정

고정 시각: 2026-10-04 01:52 KST

## 질문

제안 방법("세션 일관 표현 학습")은 fine-tuning 중에 **학습 피험자의 세션 간 클래스
방향을 일치시키는 손실**을 더한다.  그 전에 세 가지를 확인한다.

## 측정 (캐시된 특징, GPU 불필요)

각 fold 모델(테스트 피험자 ts)에서 피험자를 역할로 나눈다:
**학습**(기울기 받음), **검증**(2명, 기울기 없음), **테스트**(1명).

피험자 s, 세션 a 마다 세션 평균 μ_{s,a} 로 중심화한 뒤, 감정 c 의 클립 임베딩 평균을
prototype Q_{s,a,c} 로 둔다 (L2 정규화한 CLS, 조건4 경로와 같은 표현).

| 지표 | 정의 |
|---|---|
| cos_within(s) | 같은 피험자, 같은 감정, **다른 세션** prototype 사이 코사인 평균 |
| cos_between | **다른 피험자**, 같은 감정 prototype 사이 코사인 평균 |

## 판단 기준 (고정)

**P1 — 손실이 학습 데이터에서 밀어낼 것이 있는가**
학습 역할 피험자의 cos_within 평균이 **0.95 미만**이면 충족.
0.95 이상이면 학습 피험자는 이미 세션 간 일치 → 제안한 손실은 신호가 거의 없다.

**P2 — 세션 불일치가 "보지 못한 피험자" 에서 생기는가**
테스트(+검증) 역할 cos_within 이 학습 역할보다 **0.03 이상 낮으면** 충족.
이것은 불일치가 일반화 격차임을 뜻한다.

**P3 — 세션 불일치가 정확도와 관련되는가**
테스트 피험자별 cos_within 과 현실적 중심화 clip 정확도(클립 전체 예산) 의
Spearman ρ > 0, p < 0.05 (SEED 15 + SEED-V 16 = 31명 합산) 이면 충족.

## 판단 규칙

| 결과 | 다음 단계 |
|---|---|
| P1 충족, P3 충족 | 2단계로 — 손실을 설계대로 |
| **P1 미충족** (학습 피험자 이미 일치), P2 충족 | 2단계로 — 단 **손실을 바꾼다**: 학습 피험자의 한 세션을 CE 에서 빼고 일치 손실에만 쓰는 **세션 hold-out 형태** (보지 못한 세션을 학습 중에 흉내) |
| P3 미충족 | 세션 불일치가 정확도를 제한하지 않는다 → 방법 전제 약함, 분석 논문 쪽으로 |

## 참고 — 이미 알고 있는 것 (S15)

같은 피험자 세션 간 감정 방향 코사인 0.840, 그 피험자 vs 학습 prototype 0.828.
그 측정은 역할을 나누지 않았다.  이번에는 같은 모델 안에서 학습/검증/테스트 역할별로 본다.

# 결과 (2026-10-04, 위 기준을 고정한 뒤 실행)

## 역할별 세션 간 일치 (cos_within) — 같은 모델 안에서

| | 학습 | 검증 | 테스트 | 피험자 간 (학습끼리) | 테스트→학습 |
|---|---|---|---|---|---|
| SEED | **0.965** | 0.847 | 0.833 | 0.929 | 0.777 |
| SEED-V | **0.860** | 0.442 | **0.414** | 0.763 | 0.293 |

## 판정

| 기준 | SEED | SEED-V | 판정 |
|---|---|---|---|
| **P1** 학습 피험자 < 0.95 | 0.965 → **미충족** | 0.860 → 충족 | **갈림** |
| **P2** 보지 못한 피험자가 0.03 이상 낮음 | +0.124 (p=0.0006) | **+0.432** (p<0.0001) | **충족** |
| **P3** cos_within 과 정확도 Spearman | ρ=+0.33 (p=0.23) | **ρ=+0.69 (p=0.003)** | **합산 ρ=+0.53, p=0.002 → 충족** |

## 판단 규칙 적용

P1 이 주 데이터셋(SEED)에서 미충족이고 P2 는 둘 다 충족이므로, 사전 등록한 둘째 행을
따른다: **2단계로 가되 손실을 세션 hold-out 형태로 바꾼다.**

SEED-V 는 P1 을 기술적으로 충족하지만(0.860), 보지 못한 피험자와의 격차(0.432)가 학습
피험자 안의 불일치(1 − 0.860 = 0.140)보다 3배 크다 — 거기서도 일반화가 주된 문제다.

## 읽는 법

**세션 불일치는 학습의 실패가 아니라 일반화의 실패다.**  fine-tuning 은 학습 피험자의
세 세션을 전부 보므로 그들의 클래스 방향을 맞춰 놓는다(SEED 0.965).  보지 못한 피험자에서는
같은 사람의 세션끼리도 방향이 어긋난다(SEED 0.833, SEED-V **0.414**).

그래서 처음 설계한 손실("학습 피험자의 세션 간 방향을 맞춘다")은 **이미 맞춰진 곳을 민다.**
보지 못한 세션을 학습 중에 흉내 내야 한다 — 학습 피험자의 한 세션을 CE 에서 빼고 일치
손실에만 쓰는 hold-out 형태가 그것이다.

**SEED-V 의 0.414 는 새로운 발견이다.**  보지 못한 피험자는 같은 사람의 다른 날끼리도 감정
방향이 거의 일치하지 않는다(코사인 0.41).  그리고 이 일치도가 높은 피험자일수록 정확도가
높다(ρ=+0.69).  SEED-V 의 낮은 절대 정확도의 상당 부분이 여기서 온다는 가설을 세울 수 있다.

# 2a 사전 등록: 보지 못한 피험자의 세션 간 어긋남은 체계적인가

고정 시각: 2026-10-04 01:55 KST

각 fold 에서 세션 간 prototype 차이 ΔQ = Q_{s,a,c} − Q_{s,b,c} (a<b, 모든 감정) 를 모은다.

- **U_val(k)**: 검증 피험자 2명의 ΔQ 에서 뽑은 상위 k 주성분 (보지 못한 피험자 쪽 구조)
- **U_train(k)**: 학습 피험자들의 ΔQ 에서 뽑은 상위 k 주성분 (본 피험자 쪽 구조)
- **포착률**: 테스트 피험자의 ΔQ 에너지 중 그 부분공간에 들어가는 비율
- **상한**: 테스트 피험자 자신의 ΔQ 상위 k 주성분이 포착하는 비율
- **무작위 기준**: 200차원 공간에서 k차원 무작위 부분공간의 기대 포착률 k/200

**판단 기준 (k=4 고정):**  U_val 의 포착률이 **상한의 50% 이상**이고 무작위 기준의
**5배 이상**이면 "체계적" — 전역 사영이나 학습 단계 방법이 겨냥할 구조가 있다.
그렇지 않으면 "제각각" — 세션마다 따로 추정해야 하므로 학습 단계 방법의 전제가 약하다.

## 2a 결과

| | 검증 방향 포착률 (k=4) | 상한 | 검증/상한 | 무작위 대비 |
|---|---|---|---|---|
| SEED | 0.413 | 0.989 | **0.42** | 20.6배 |
| SEED-V | 0.407 | 0.864 | **0.47** | 20.3배 |

**판정: "체계적" 아님** (상한의 50% 미달, 무작위의 5배는 충족).  어긋남은 강하게 구조화돼
있지만 공유되는 몫은 약 40% 다.  상한은 테스트 피험자 자신의 차이 벡터 9~15개에 4차원을
맞춘 값이라 낙관적일 수 있으나, 기준은 결과 전에 정했으므로 판정을 유지한다.

# 2b 사전 등록: 공유된 40% 가 정확도로 이어지는가 (닫힌 형태)

고정 시각: 2026-10-04 01:56 KST

학습 단계 방법(GPU) 전에, 같은 아이디어를 닫힌 형태로 시험한다.

- 각 fold 에서 **검증 피험자 2명**의 ΔQ 상위 k=4 주성분 U 를 뽑는다 (테스트 피험자 안 씀)
- 모든 창의 L2 정규화 특징에서 사영 제거: z′ = z − U Uᵀ z
- 나머지는 그대로 — 현실적 캘리브레이션 중심화, prototype, 같은 난수·같은 클립
- 비교: 사영 없음 (기존 중심화) 대 사영 있음

**판단 기준:**  clip 정확도 Δ(사영 − 기존) 가 **두 데이터셋 모두 +0.015 이상** (감정별 20초와
클립 전체 예산), 그리고 Holm 보정 p < 0.05 가 하나 이상이면 **3단계(GPU 학습)로 간다.**
그렇지 않으면 **전역·학습 단계 경로를 닫는다** — 남은 60% 는 세션마다 따로 추정해야 하고,
라벨 없이는 그것이 실패한다는 것을 M2 가 이미 보였다.

## 2b 결과

| | SEED Δ (사영 − 기존) | p | SEED-V Δ | p |
|---|---|---|---|---|
| clip, 감정별 20초 | −0.0070 | 0.64 | **−0.0190** | **0.023** (3/16) |
| clip, 감정별 40초 | −0.0086 | 0.48 | **−0.0210** | **0.013** (3/16) |
| clip, 클립 전체 | −0.0024 | 0.98 | **−0.0253** | **0.001** (1/16) |
| window, 클립 전체 | −0.0025 | 0.56 | −0.0109 | 0.034 |
| 테스트 세션 일치도 | 0.833 → 0.807 | 0.055 | 0.414 → 0.388 | 0.025 |

**판정: 미충족 — 방향까지 반대다.**  사전 등록한 규칙대로 **전역·학습 단계 경로를 닫는다.**

### 왜 해로운가

공유된 "세션 간 차이 방향" 을 빼면 테스트 피험자의 세션 일치도가 **오르지 않고 내려간다**
(0.833→0.807, 0.414→0.388).  세션 사이에서 달라지는 방향이 감정 방향 **그 자체**이기 때문이다
— 감정 부분공간이 세션마다 회전하므로, 회전하는 방향을 지우면 감정 신호를 지운다.  어긋남은
감정 정보와 얽혀 있어서 떼어낼 수 없다.

### 한계

닫힌 형태의 선형 제거는 학습 단계 방법의 대리 실험이다.  학습된 변환은 제거가 아니라 정렬을
할 수 있으므로 이 결과가 학습 단계 방법을 **완전히** 배제하지는 않는다.  다만 2a(공유 40%)와
2b(제거는 해로움)가 같은 방향을 가리키고, 둘 다 결과 전에 고정한 기준에서 실패했다.

# V3 종합: 남은 오차의 정체

| 성분 | 측정 | 결론 |
|---|---|---|

| 회전 (클래스 방향) | oracle +0.03~0.06 | 남은 오차 |
| 회전은 어디서 | 본 피험자 0.965, 보지 못한 피험자 0.833 / **0.414** | **일반화 실패** |

**결론: 이 FM 에서 라벨 없는 적응은 중심화 근처가 천장이다.  남은 오차는 사용자·세션마다
다른 회전이고, 그것을 추정하려면 그 세션의 라벨이 필요하다.**
